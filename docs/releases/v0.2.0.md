## Security notice: v0.1.0 is withdrawn

The v0.1.0 binaries were built by hand from source that was never published,
and they have a private gateway hostname compiled in. The v0.1.0 tag also
contains no Go source, so `go install …@v0.1.0` never worked. v0.1.0 is
withdrawn and its binaries have been removed from the release.

If you installed v0.1.0 (Homebrew, Scoop or a direct download), upgrade to
v0.2.0 or remove it:

```bash
brew update && brew upgrade relay          # Homebrew
scoop update; scoop update relay           # Scoop
go install github.com/patrikmichi/relay/cmd/relay@v0.2.0
```

If you ran `relay login` with v0.1.0, run `relay logout` (or remove the
`relay` entries from your OS keychain) and sign in again against a gateway
you choose.

## Breaking changes

- **No default gateway.** relay no longer ships with a gateway URL. Gateway
  commands fail closed with guidance until you configure one:
  `relay config set-gateway <url>` or `export GATEWAY_URL=<url>`. Every local
  command (`relay skill …`, `relay agent …`, `relay providers`) works with no
  gateway.
- **HTTPS only.** Gateway URLs must use https; plain http is accepted only
  for localhost. HTTP redirects are refused.
- **One session per gateway.** Sessions are now bound to the gateway they
  were issued by. A session saved by an older relay moves automatically when
  the gateway saved with `relay config set-gateway` uses https; otherwise
  relay asks you to run `relay login` once.
- **Exit status 4** when a gateway request hits relay's time limit, and tool
  failures reported by the gateway (`isError`) now exit non-zero.
- **Release assets** are archives only: `relay-<os>-<arch>.tar.gz` (macOS,
  Linux) and `relay-<os>-<arch>.zip` (Windows). The bare, unarchived binaries
  from v0.1.0 are gone. Checksums stay in `SHA256SUMS.txt`.

## Features

- Skill management (`relay skill migrate/install/list/diff/scan/score/uninstall/rollback`)
  across 7 providers: Claude Code, Codex, opencode, Cursor, Cline, Gemini CLI
  and Windsurf.
- Agent management (`relay agent migrate/list/diff/scan/uninstall/rollback`)
  across 5 providers: Claude Code, opencode, Codex, Cursor and Gemini CLI.
- `relay agent install <catalog-id>` installs an agent from a gateway catalog
  with the same checksum and scan gates as `relay skill install`.
- `relay mcp list` lists the catalog's MCP servers (read-only).
- `relay sync --to <provider>` is rejected with the portable alternative.
- `relay --version` reports the module version for `go install` builds.
- `relay doctor` checks provider directories, installed files, recovery
  state and gateway authentication. `relay call --json` prints the raw
  JSON-RPC response.
- Per-request time limits: 30s for gateway requests and 150s for tool calls
  and uploads, set with `--timeout` or `RELAY_TIMEOUT` (`0` disables).
- `relay recover` and `relay history` inspect and finish interrupted skill
  and agent writes.
- Requests send `User-Agent: relay/<version> (<os>/<arch>)` and
  `Relay-Client-Version`; relay sends no other telemetry.

## Distribution

- Built by goreleaser from the tagged commit on `main`, with no gateway
  hostname. CI fails the release if any binary contains a denylisted hostname.
- `go install github.com/patrikmichi/relay/cmd/relay@v0.2.0` works; the
  release workflow runs it before publishing.
- Targets: macOS, Linux and Windows on amd64 and arm64 (adds Linux arm64).
- Homebrew formula and Scoop manifest are generated from this release.
- `SHA256SUMS.txt` is signed with Sigstore cosign (keyless), each archive has
  an SPDX SBOM, and every archive has a GitHub build provenance attestation.

## Verify a download

```bash
cosign verify-blob SHA256SUMS.txt \
  --bundle SHA256SUMS.txt.sigstore.json \
  --certificate-identity "https://github.com/patrikmichi/relay/.github/workflows/release.yml@refs/tags/v0.2.0" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
sha256sum --ignore-missing -c SHA256SUMS.txt
gh attestation verify relay-linux-amd64.tar.gz --repo patrikmichi/relay
```
