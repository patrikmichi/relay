## Packaging fix

v0.2.0 published its archives but not its Homebrew formula or Scoop manifest,
and its archives carry no build provenance attestation. v0.2.1 is the same
code with packaging fixed: install it through Homebrew or Scoop, or upgrade
from v0.1.0 or v0.2.0.

```bash
brew update && brew upgrade relay          # Homebrew (patrikmichi/tap)
scoop update; scoop update relay           # Scoop (patrikmichi bucket)
go install github.com/patrikmichi/relay/cmd/relay@v0.2.1
```

See the [v0.2.0 notes](https://github.com/patrikmichi/relay/releases/tag/v0.2.0)
for features and breaking changes (no default gateway: run
`relay config set-gateway <url>` once).

## Security notice: v0.1.0 is withdrawn

The v0.1.0 binaries have a private gateway hostname compiled in and were
built from unpublished source. If you installed v0.1.0, upgrade or remove it.
If you ran `relay login` with v0.1.0, run `relay logout` and sign in again
against a gateway you choose.

## Verify a download

```bash
cosign verify-blob SHA256SUMS.txt \
  --bundle SHA256SUMS.txt.sigstore.json \
  --certificate-identity "https://github.com/patrikmichi/relay/.github/workflows/release.yml@refs/tags/v0.2.1" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
sha256sum --ignore-missing -c SHA256SUMS.txt
gh attestation verify relay-linux-amd64.tar.gz --repo patrikmichi/relay
```
