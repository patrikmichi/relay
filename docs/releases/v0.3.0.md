## What's new

- **`relay sync` across coding agents.** One command writes MCP servers,
  environment, hooks, rules, commands, skills and subagents into Claude Code,
  Codex, Cursor, OpenCode, Gemini CLI, Windsurf, Cline and GitHub Copilot.
  Entries relay writes are tracked in a hash ledger; anything you wrote
  yourself is reported as a conflict and left alone unless you pass `--force`.
  `--to`, `--from`, `--kind`, `--scope`, `--dry-run` and `--matrix` select and
  preview what changes. Edits go through a journaled transaction, so an
  interrupted write is finished or undone by `relay recover`.
- **`relay mcp install` and `relay mcp remove`** register an MCP server in
  every agent. `${VAR}` references are translated to each agent's own syntax;
  an agent that cannot expand them is skipped and reported.
- **Gateway connectors:** `relay connectors`, `relay connect <service>` and
  connection status in `relay services`.
- **Approvals:** `relay approvals list|show|approve|deny|wait`, `--wait` on
  `relay call`, and `relay explain` names the approval a tool needs. The
  agent profile (`relay login --agent`, `RELAY_AGENT`) gets its own session.
  `RELAY_AGENT` selects a profile; it is not a security boundary.
- **Skill evals:** sets and cases, `relay skill eval`, `relay skill compare`,
  optimization drafts and quality history, with `--fail-on-regression` for CI.
- **Skill requirements:** installing a skill checks the connectors it needs
  and offers `relay connect` for the missing ones; `relay skill info`.
- **Signed downloads:** catalog downloads and plugin bundles are verified
  against Ed25519 keys pinned per gateway.
- **`relay doctor`** checks synced MCP servers, hooks, rules and commands.

## Breaking changes and migration

- **Bare `relay sync` now syncs coding agents.** It used to pull the
  Claude Code plugin marketplace. Pull the marketplace with
  `relay sync --marketplace` (or `--dir <path>`).
- **Unattended hook and stdio writes need `--yes`.** Adding or changing a
  hook, a local MCP command, the gateway URL, or a project's rules or remote
  MCP servers asks for confirmation in a terminal. Without one, review with
  `--dry-run` and pass `--yes`.
- **Sync is refused while `RELAY_AGENT` is set.** An agent must not widen its
  own tools or hooks. `--yes` does not override this; run the command from a
  normal shell.
- **Sessions are bound per gateway and profile.** A session saved by an older
  relay moves automatically when the gateway saved with
  `relay config set-gateway` uses https; otherwise run `relay login` once. The
  agent profile never falls back to your own session: run
  `relay login --agent`.
- **`relay logout` and `relay tokens revoke` exit non-zero** when the gateway
  did not revoke the session ("NOT revoked on gateway"). The local session is
  still removed.
- **`--fail-on-regression` exits 20** when the run scored no cases or some
  ended in an error.
- **Go 1.26 or newer is required for `go install`.** Release archives and
  package-manager installs are unaffected.
- **Local timeout flags are renamed to `--wait-timeout`.** The old names are
  gone with no alias.
- **`relay authorize --scope` is now `--tool`.** `--scope` means `user` or
  `project` everywhere else. No alias.
